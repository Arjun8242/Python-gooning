You need to establish a Python function using FastAPI that will accept inputs in JSON format—specifically, {"distance": <float>, "average_speed": <float>, "delay": <int>} where distance is in kilometers, average_speed is in kilometers per hour, and delay is in minutes. The expected output should be a JSON response with keys: "eta" for the estimated time of arrival in hours and minutes format, along with "status_code" reflecting whether the operation was successful or if there were input validation issues (400 for bad requests). Assume proper error handling must also be implemented for invalid data types or missing fields. To meet these requirements effectively, prepare pseudocode representing your API endpoint logic incorporating both HTTP GET methods for fetching ETA details and utilizing appropriate status codes when responding back to clients.
